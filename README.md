# 🏥 Healthcare Data Analysis and Visualization Using Excel

## 📌 Project Overview

This project focuses on analyzing healthcare data using Microsoft Excel to understand patient demographics, disease distribution, medication usage, and age-related patterns.

The dataset contains patient-level information, including age, gender, disease, medication, and dosage. The project involves exploring the dataset, cleaning and organizing the data, performing basic analysis, and creating visualizations to identify meaningful healthcare insights.

## 🎯 Project Objectives

- Explore and understand the healthcare dataset.
- Identify and handle missing values and duplicate records.
- Analyze patient demographics and healthcare trends.
- Identify the most common diseases and medications.
- Calculate key statistics, including patient count and average age.
- Create charts and graphs to communicate findings effectively.

## 🛠️ Tools and Skills

- **Microsoft Excel**
- Data Cleaning and Preparation
- Data Exploration
- Descriptive Analysis
- Excel Formulas
- PivotTables and PivotCharts
- Data Visualization
- Healthcare Data Interpretation

## 🧹 Data Cleaning and Preparation

The following activities were performed:

- Explored the dataset structure and column types.
- Identified missing values and duplicate records.
- Removed 20 duplicate records.
- Standardized inconsistent entries.
- Checked age and dosage values.

## 📊 Key Results

| Metric | Result |
|---|---:|
| Total Records Before Cleaning | 320 |
| Duplicate Records Removed | 20 |
| Duplicate Records Removed (%) | 6.25% |
| Final Unique Records | 300 |
| Average Patient Age | 43.9 years |
| Average Dosage | 542.32 |

## 📈 Data Visualization

The project includes the following visualizations:

- **Gender Distribution:** Male, female, and unknown gender categories.
- **Age Distribution:** Patient counts across five age groups.
- **Disease Distribution:** Comparison of the most common diseases.
- **Medication Usage:** Comparison of the five most frequently recorded medications.
